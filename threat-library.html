The Threat Library

An encyclopedia of critical vulnerabilities. Learn how these exploits function in the wild and how SecureLayer engineers discover and remediate them.

Broken Access Control (BAC)

Critical 9.1

What it is: When an application fails to properly enforce restrictions on what authenticated users are allowed to do. Attackers can view sensitive files, modify other users' data, or change access rights.

How SecureLayer Finds It: Automated scanners almost always miss BAC because they lack business logic context. Our engineers manually map user roles and manipulate API parameter IDs (IDOR) to bypass tenant isolation boundaries.

Server-Side Request Forgery (SSRF)

High 8.5

What it is: A vulnerability that allows an attacker to induce the server-side application to make HTTP requests to an arbitrary domain of the attacker's choosing. This is notoriously used to compromise AWS metadata endpoints (169.254.169.254) and steal IAM cloud credentials.

How SecureLayer Finds It: We identify endpoints that fetch external resources (like PDF generators or webhook handlers) and inject internal IP addresses or cloud metadata URLs to pivot into your internal network.

Remote Code Execution (RCE)

Critical 10.0

What it is: The holy grail of hacking. An attacker can execute arbitrary operating system commands on the server running an application, leading to a complete system takeover.

How SecureLayer Finds It: We look for insecure deserialization, flawed file upload parsers, or vulnerable third-party dependencies (like Log4j). We then craft highly specific payloads to gain a reverse shell into the environment.

SQL Injection (SQLi)

High 8.8

What it is: Injection of malicious SQL queries via client input. It allows an attacker to view data they shouldn't, modify/delete data, or even escalate to RCE in certain database configurations.

How SecureLayer Finds It: While standard scanners test obvious parameters, we manually fuzz complex, nested JSON objects, GraphQL queries, and heavily filtered inputs using advanced time-based and blind SQLi techniques.
